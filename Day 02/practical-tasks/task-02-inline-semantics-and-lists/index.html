Keyboard & semantics mini cheat sheet

Important: This is a note about something important. This text is marked for emphasis.

To save your work, press Ctrl + S (or Cmd + S on Mac). You can also use the git commit command to save changes in your version control system.

CSS is a stylesheet language used to describe the presentation of a document written in HTML.

Shortcuts

  • Ctrl + C — Copy selected text or items.
  • Ctrl + V — Paste copied text or items.

Setup order

  1. Install the necessary software.
  2. Configure the development environment.

Glossary

HTML
Hypertext Markup Language, the standard language for creating web pages.
JavaScript
A programming language used to create interactive effects within web browsers.
