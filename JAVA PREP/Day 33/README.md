# Day 33 — Spring Data JPA II: Derived Queries, JPQL, Native SQL, Paging and Projections

## Learning objectives

- Write derived query methods
- Use @Query with JPQL, native SQL and @Modifying
- Paginate with Page/Slice/Pageable/Sort
- Choose among interface, open, DTO and dynamic projections

## Prerequisites

- Day 32 Spring Data JPA I

## Spring Boot version note

Course target is Spring Boot 4 when available; labs pin 3.4.x for reproducible builds.

## How to use this folder

1. Read [`DAY-33-THEORY-AND-REFERENCE.md`](DAY-33-THEORY-AND-REFERENCE.md) first.
2. Open each task folder as its own Maven project in IntelliJ.
3. Run `mvn test` (red) -> implement the `TODO(DayXX-taskYY)` markers -> `mvn test` (green).
