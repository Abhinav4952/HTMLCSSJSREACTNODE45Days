# Task 1 — Create Tables and Constraints

**Day:** 25 · **Task ID:** Day25-task01 · **Type:** SQL script + JDBC test · **Difficulty:** Warm-up

## Summary

Write PostgreSQL-style DDL for a small shop schema (customers, products, orders) with PK, FK, UNIQUE, CHECK, NOT NULL and defaults, then prove each constraint with violating inserts.

## What you will implement

1. Create `customers`, `products`, `orders` in `sql/schema.sql` with the exact column names from the TODO comments.
2. Use identity primary keys, a UNIQUE email and sku, NOT NULL where specified, a CHECK on price and order status, and defaults for `created_at`, `status`, `placed_at`.
3. Add the foreign key `orders.customer_id -> customers.id`.
4. Fill the two blocks in `sql/answers.sql` (keep the `-- @name` markers).

## Constraints

- Java 21; plain JDBC/SQL only (no Spring, no Lombok); H2 2.3.232 in PostgreSQL mode is the only database.
- Do not edit test files or this document; edit only the places marked `TODO(Day25-task01)`.
- Do not hard-code values just to satisfy a test — implement real behavior.
